# IGCSE Paper Forge

**Live site:** https://daniellaffan.github.io/igcse-paper-forge/

A free website that makes **practice exam papers and mark schemes** for these IGCSE subjects:

| Subject | Board and code | What's covered |
|---|---|---|
| Mathematics A (Higher) | Pearson Edexcel 4MA1 | Papers 1H and 2H |
| Further Pure Mathematics | Pearson Edexcel 4PM1 | Papers 1 and 2 |
| Physics | Pearson Edexcel 4PH1 | Papers 1 and 2 (Paper-2-only content is labelled) |
| Chemistry | Pearson Edexcel 4CH1 | Papers 1 and 2 |
| Biology | Pearson Edexcel 4BI1 | Papers 1 and 2 |
| Economics | Pearson Edexcel 4EC1 | Papers 1 and 2 |
| History | Pearson Edexcel 4HI1 | Germany 1918–45, A world divided 1943–72, Russia 1905–24, America 1783–1877 |
| English Language A | Pearson Edexcel 4EA1 | Paper 1 |
| English Literature | Pearson Edexcel 4ET1 | Paper 1 (unseen poetry, anthology poetry, *Of Mice and Men*) |
| Spanish | Cambridge IGCSE 0530 | Listening, Reading, Speaking, Writing |

> **Practice paper — not an official exam board paper.** Every question was written for this project.
> Nothing here is made or endorsed by Pearson, Edexcel or Cambridge. Use the official past papers too:
> each subject page links to them.

## Using the site

1. Pick a subject on the home page.
2. Tick the topics you have studied (the site remembers your ticks on your device).
3. Press **Build a paper**. Choose a **topic test** (only your ticked topics, any length) or a
   **full paper** (the same structure, marks and timing as the real exam).
4. Read it on screen, or press **Question paper PDF** / **Mark scheme PDF** to download A4 PDFs to print.
5. **Copy link** gives a link that rebuilds exactly the same paper, which is handy for sharing with a friend or teacher.

The site remembers which questions you have already seen and avoids repeating them until you reset.
It does not use cookies, tracking or analytics.

For Spanish listening, the site reads the recording aloud with your browser's Spanish voice (press ▶ Play).
Each recording plays twice, as in the exam. The transcript is in the mark scheme.

## Running it on your own computer

You need [Node.js](https://nodejs.org) 20 or newer and Python 3.11 or newer.

```bash
python3 -m venv .venv
.venv/bin/pip install jsonschema pymupdf
.venv/bin/python scripts/build_site_data.py      # copies the question bank into the website
cd site && npm install && npm run dev            # then open the address it prints
```

## Where things are

| Folder | What's in it |
|---|---|
| `data/spec/` | Each subject's specification as data: papers, sections, topics, spec points |
| `data/bank/<subject>/` | The question bank: every question with its mark scheme (JSON) |
| `data/reference/` | Formula sheets and data pages printed with some papers |
| `style-guides/` | Notes on how each real paper is written and laid out |
| `scripts/gen/` | The programs that generate each subject's questions |
| `scripts/` | Checks: `validate_bank.py` (format, marks, coverage), `similarity_check.py` (not copied from real papers) |
| `site/` | The website (React + Vite) |
| `docs/` | Reports: `BANK_REPORT.md`, `SCOPE_NOTES.md`, `CORPUS_GAPS.md`, `verification/` |

## Adding or changing questions

Questions are generated by the Python files in `scripts/gen/` (one main file per subject, e.g.
`scripts/gen/physics.py`). The format is described in `docs/DATA_FORMAT.md`.

```bash
.venv/bin/python scripts/gen/physics.py          # regenerate one subject's bank
.venv/bin/python scripts/validate_bank.py        # must say OK
.venv/bin/python scripts/similarity_check.py     # must flag nothing (needs the private corpus)
.venv/bin/python scripts/build_site_data.py      # update the website's copy
```

You can also hand-edit a question in `data/bank/<subject>/*.json`, but it is overwritten the next
time that subject's generator runs.

When you push to GitHub, the site checks the bank automatically and only publishes if it is valid.

## Rebuilding the private corpus

The generators were written by studying real past papers, mark schemes and examiner reports. These are
copyright Pearson / Cambridge, so they are **never committed**: `corpus/` and `corpus_text/` are
in `.gitignore`, and the deploy workflow refuses to publish if any corpus file is tracked.

To rebuild them on your own computer (only freely downloadable files; nothing behind a login):

```bash
.venv/bin/pip install requests
.venv/bin/python scripts/fetch_corpus.py                  # downloads into corpus/, writes corpus/manifest.json
.venv/bin/python scripts/extract_text.py                  # text versions into corpus_text/
.venv/bin/python scripts/corpus_report.py                 # updates docs/CORPUS_GAPS.md
```

What could not be downloaded is listed in [`docs/CORPUS_GAPS.md`](docs/CORPUS_GAPS.md).
